# Checkpoint 1 - Web Development 

Este repositório contém a resolução do **Checkpoint 1** da disciplina de Web Development. O projeto consiste em 10 programas desenvolvidos em JavaScript nativo, focados em lógica de programação e exibição de resultados diretamente na consola do navegador.

##  Funcionalidades Desenvolvidas

O script (`js/script.js`) executa sequencialmente os seguintes algoritmos:

1. **Operadores Lógicos:** Demonstração prática dos operadores `!=`, `===` e `>=`.
2. **Cálculo de IMC:** Algoritmo que calcula o Índice de Massa Corporal com base no peso e altura utilizando estruturas condicionais encadeadas (`if/else if/else`).
3. **Estrutura de Repetição:** Loop de contagem incremental de 1 até 10 utilizando o laço `for`.
4. **Manipulação de Arrays:** Listagem e iteração de um array contendo os heróis da Marvel na consola.
5. **Operador Ternário:** Verificação simplificada de permissão de acesso de um utilizador.
6. **Sistema de Autenticação:** Simulação de validação de login utilizando utilizador e senha pré-cadastrados.
7. **Cálculo de Média Escolar:** Processamento de 7 notas de um aluno para determinar aprovação (Média mínima: 6).
8. **Template Strings:** Manipulação de Strings utilizando interpolação com crases (`` ` ``).
9. **Modificação de Credenciais:** Sistema de validação para alteração de senha, impedindo a reutilização da senha atual.
10. **Cálculo de Desconto:** Subtração básica utilizando variáveis de preço e desconto para obter o valor final de um produto.

##  Tecnologias Utilizadas

* **HTML5:** Estrutura básica para carregar e executar os scripts.
* **JavaScript (ES6):** Lógica principal de programação e manipulação de dados na consola.
* **Git & GitHub:** Controlo de versão utilizando boas práticas de commits semânticos.

## Como Executar o Projeto

1. Clona este repositório ou faz o download da pasta do projeto.
2. Abre o ficheiro `index.html` em qualquer navegador web (Google Chrome, Edge, Firefox, etc.).
3. Abre as **Ferramentas do Desenvolvedor** do navegador (atalho `F12` ou clique direito -> *Inspecionar*).
4. Navega até ao separador **Console** (Consola) para visualizar a saída organizada de todos os exercícios.
